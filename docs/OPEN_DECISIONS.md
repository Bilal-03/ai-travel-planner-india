## Landmark catalogue source and release policy — approved 2026-08-03

- **Owner:** Product and engineering
- **Due date:** 2026-08-10
- **Decision:** Approved: use official state tourism, ASI, UNESCO, and other
  authoritative heritage sources for editorial prominence; use an attributed,
  licence-reviewed geographic source only for coordinates. Review each record
  at least every 180 days and earlier where a mutable dependency is known.
- **Next milestone:** Implement the versioned catalogue schema and first
  reviewed destination batch.
