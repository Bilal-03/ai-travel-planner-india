# Open decisions

## Landmark catalogue source and release policy — approved 2026-08-03

- **Owner:** Product and engineering
- **Due date:** 2026-08-10
- **Decision:** Approved: use official state tourism, ASI, UNESCO, and other
  authoritative heritage sources for editorial prominence; use an attributed,
  licence-reviewed geographic source only for coordinates. Review each record
  at least every 180 days and earlier where a mutable dependency is known.
- **Implementation status (2026-08-03):** The versioned schema and a first
  high-demand batch are implemented. Mumbai, Delhi, Jaipur, Agra, Goa,
  Bengaluru, Chennai, Kolkata, Hyderabad, Varanasi, Udaipur, Rishikesh,
  Manali, Kochi, Srinagar, Amritsar, Lucknow, Mysuru, Jodhpur, Shimla, Ooty,
  Munnar, Pondicherry, Madurai, Tirupati, Darjeeling, and Ayodhya each have
  twelve reviewed records. The remaining milestone is a separate regional
  rollout with the same source-review process.
